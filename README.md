# El Coqui

El Coqui is a 2D/2.5D metroidvania inspired by Puerto Rican folklore, movement-focused platforming, and tongue-based traversal.

## Play the Game
[Play the WebGL Build](https://acruzgo.github.io/el-coqui-play/)

## Game Design Document
[Read the full GDD on Notion](https://languid-geese-db1.notion.site/Game-Design-Document-e7989a6c21ca82368d4c019abe610686?source=copy_link)

## Current Prototype Features
- Responsive jumping and double jumping
- Wall jumping
- Dash movement
- Tongue grappling
- Combat
- Tutorial prompts
- Boss encounter
- Original worldbuilding and narrative direction

## Built With
- Unity — game engine
- C# — gameplay systems and scripting
- Unity Input System — keyboard/controller input
- Git/GitHub — version control
- Notion — Game Design Document and development planning
- Astra-6 / Codex — AI-assisted development, prototyping, debugging, and iteration
